# IronRDP USB

Protocol-independent USB data structures and sans-I/O semantics for IronRDP.

This foundational crate is intended to provide USB-standard data models, parsing, validation, and query operations shared by protocol adapters.
It does not perform device I/O or define RDPEUSB-, usbredir-, or runtime-specific behavior.

This crate is part of the [IronRDP] project.

[IronRDP]: https://github.com/Devolutions/IronRDP
